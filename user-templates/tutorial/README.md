# 🤖 Welcome to the GO Agent Tutorial! 🤖 

This is intended as a highly interactive tutorial. You should let Claude be your guide in the tutorial.

To continue with the tutorial, find the window marked "Claude Code" (if you don't see one, select File >> New >> Terminal, and hit Enter)

Some useful commands:

While you can type whatever you want in the Claude window, for this tutorial we will be using some pre-built *commands* to help us along.

Commands start with a forward slash (`/`) symbol. 

To start an exercise such as exercise 1, type `/exercise 1`


    -------------------
    > /exercise 1
    -------------------

To recap an exercise, use the `/recap` command
